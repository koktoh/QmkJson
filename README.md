# QmkJson

QMKのキーボード設定ファイルを扱うためのC#モデルとJSONシリアライズ機能です。  
C# models and JSON serialization support for QMK keyboard configuration files.

QMK Firmware **0.34.4** の[JSONスキーマ](https://github.com/qmk/qmk_firmware/blob/0.34.4/data/schemas/keyboard.jsonschema)におおむね対応しています。  
Supports most of the [JSON Schema](https://github.com/qmk/qmk_firmware/blob/0.34.4/data/schemas/keyboard.jsonschema) for QMK Firmware **0.34.4**.

バリデーション機能はありません。  
No validation is provided.
